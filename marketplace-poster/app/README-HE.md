# Marketplace Poster V2 — Windows

גרסה עם ממשק ניהול מקומי ל-Facebook Marketplace. הממשק נפתח בדפדפן על `127.0.0.1` בלבד, והנתונים נשמרים במחשב שלך.

## בנייה ל-EXE

1. התקן Google Chrome.
2. ודא ש-Go מותקן (`go version`). Go 1.22 ומעלה מספיק; Go 1.27.1 תקין.
3. חלץ **את כל ה-ZIP** לתיקייה רגילה. אל תריץ BAT מתוך ה-ZIP.
4. לחץ פעמיים על `BUILD_EXE.bat`.
5. בסיום ייווצר:

```text
dist\MarketplacePoster.exe
```

לביצוע התקנה עם קיצור דרך לשולחן העבודה ולתפריט Start, לחץ לאחר הבנייה על:

```text
INSTALL.bat
```

`UNINSTALL.bat` מסיר את ה-EXE והקיצורים, אבל משאיר את המודעות וההגדרות שלך.

## מה נוסף ב-V2

### מודעות
- יצירה, עריכה, מחיקה, שכפול וארכיון.
- חיפוש, סינון ומיון.
- עריכה מרובה למחיר / קטגוריה / מצב.
- עד 10 תמונות למודעה.
- Drag & Drop לתמונות לפני שמירה.
- בחירת תמונה ראשית.
- סיבוב תמונה לפני העלאה.
- מחיקת תמונות מתוך מודעה קיימת.
- בחירת כמה תמונות מתוך המודעה יישלחו לפייסבוק.
- מניעת כפילויות לפי כותרת + מחיר + תוכן התמונות.

### גרסאות טקסט
- כמה גרסאות לכותרת.
- כמה גרסאות לתיאור.
- בחירה לפי הסדר A/B/C, אקראית, או תמיד גרסה ראשונה.
- Spintax, לדוגמה:

```text
{שולחן סלון מודרני|שולחן סלון מעוצב|שולחן בהתאמה אישית}
```

- נשמרת בהיסטוריה הגרסה המדויקת שבה השתמשה התוכנה.

### תבניות
- תבניות כותרת / תיאור / קטגוריה / מצב / תגיות.
- משתנים כגון:

```text
{{PRODUCT}}
{{SIZE}}
{{COLOR}}
{{PRICE}}
```

בעת שימוש בתבנית התוכנה מבקשת את הערכים וממלאת אותם.

### תור פרסום
- בחירת המודעות שייכנסו לתור.
- הגבלת כמות בהרצה.
- מגבלה יומית.
- השהיה מינימלית ומקסימלית בין מודעות.
- עצירה לאחר מספר שגיאות שהוגדר.
- שמירת נקודת המשך (`Resume`) אם ההרצה הופסקה.
- מצב Preview: ממלא את הטופס ב-Chrome ומחכה לאישור לפני Publish.
- מצב בדיקה בלבד: ממלא את המודעה אך לא מפרסם.
- כפתור Stop.

### טיפול בשגיאות — כולל הדרישה של 60 שניות
כשפרסום נכשל התוכנה:
1. מצלמת Screenshot של הדף.
2. מציגה את השגיאה בממשק.
3. נותנת אפשרויות:
   - `נסה שוב`
   - `דלג`
   - `פתח ידנית / עצור`
4. מתחילה טיימר, כברירת מחדל **60 שניות**.
5. אם לא נבחרה פעולה עד סוף הטיימר — המודעה מסומנת כדולגה והתור ממשיך אוטומטית.

ניתן לשנות את הטיימר בהגדרות.

### Facebook Accounts
- כמה חשבונות Facebook.
- Chrome Profile נפרד לכל חשבון.
- מעבר בין חשבונות מתוך התוכנה.
- ניתן לבחור חשבון גם ברמת מודעה.
- אם הייתה לך גרסת V1 עם `browser_profile`, חשבון ברירת המחדל ממשיך להשתמש בו כדי לא לאבד את ה-Session הקיים.

### קבוצות
- פרסום לקבוצות כבוי כברירת מחדל.
- רשימת קבוצות מועדפות בהגדרות.
- קבוצות ספציפיות לכל מודעה.
- מגבלה לכמות קבוצות למודעה. 0 = כל הקבוצות ששמרת/בחרת במפורש.
- כפתור "בחר את כל הקבוצות ששמרתי" ממלא את כל הרשימה המאושרת שלך.
- המערכת לא מסמנת אוטומטית קבוצות Facebook אחרות או קבוצות מוצעות שלא בחרת.

### Dashboard והיסטוריה
- כמה מודעות פעילות וממתינות.
- כמה פורסמו / נכשלו / דולגו היום.
- זמן פרסום ממוצע.
- היסטוריה מפורטת.
- קישור למודעה כאשר Facebook מחזיר URL מתאים.
- Screenshot של תקלה.

### CSV / תיקיות
- ייצוא CSV לפתיחה ב-Excel.
- ייבוא CSV.
- ייבוא תיקיית מוצרים: כל תיקיית משנה היא מוצר, עם תמונות ו-`description.txt` בפורמט של הפרויקט המקורי.
- מודעה שיובאה מ-CSV בלי תמונות מסומנת `חסרות תמונות` עד שתוסיף לה תמונות.

### גיבוי ושחזור
- יצירת ZIP מתוך התוכנה.
- שחזור ZIP.
- הגיבוי כולל state, מודעות ותמונות.
- הגיבוי **לא** כולל את Chrome Profiles / Facebook Sessions.

### נעילת PIN
- אפשר להגדיר PIN מקומי בהגדרות.
- ה-PIN נשמר כ-SHA-256 hash ולא כטקסט גלוי.
- לאחר הפעלה מחדש נדרשת פתיחה מחדש באמצעות ה-PIN.

### Gemini — אופציונלי
Gemini אינו נדרש להפעלת התוכנה. אם תוסיף API Key בהמשך אפשר להשתמש ב:
- שיפור תיאור.
- קיצור תיאור.
- תיקון כתיב.
- יצירת כותרות חלופיות.
- יצירת תגיות.

אם Gemini כבוי, כל שאר התוכנה ממשיכה לעבוד רגיל.

### Dark Mode והתראות
- ממשק RTL בעברית.
- Dark Mode.
- התראות בדפדפן / Windows כאשר הרצה מסתיימת או מתרחשת שגיאה משמעותית.

### עדכונים
יש מנגנון Update Manifest אופציונלי. כדי להשתמש בו צריך לאחסן קובץ JSON ב-HTTPS. דוגמה נמצאת בקובץ:

```text
UPDATE-MANIFEST-EXAMPLE.json
```

התוכנה בודקת גרסה ומורידה EXE רק כאשר ה-manifest מכיל SHA-256 תואם.

## מה לא הוספתי לפי הבקשה שלך

- **27** — התרעה על תמונה קטנה / פגומה: לא הוסף.
- **28** — מנגנון נפרד לשמירת סדר תמונות אחרי השמירה: לא הוסף. אפשר לקבוע את הסדר בזמן יצירת המודעה באמצעות Drag & Drop.
- **93** — SQLite: לא הוסף. המידע נשאר ב-JSON.

## איפה הנתונים נשמרים

ב-Windows:

```text
%APPDATA%\MarketplacePoster
```

הקבצים/תיקיות העיקריים:

```text
state.json
items\
accounts\
screenshots\
backups\
updates\
app.log
```

`state.json` מכיל את המודעות, ההיסטוריה, התבניות, החשבונות וההגדרות.

## חשוב לגבי Facebook

Facebook משנה את מבנה Marketplace מעת לעת. הקוד מנסה לזהות גם עברית וגם אנגלית, ובמקרה ששדות מרכזיים כבר לא מזוהים הוא עוצר את המודעה במקום להמשיך בצורה שגויה. Screenshot ולוג נשמרים כדי שיהיה אפשר לעדכן את ה-selectors.

מומלץ להתחיל עם מודעה אחת במצב Preview ולוודא שהקטגוריה, המצב, התמונות והטקסט מזוהים נכון לפני הרצה גדולה יותר.
