# Как повысить шанс найти НУЖНУЮ запчасть

После **F8** поиск идёт так:

1. **Сначала ваши Excel** в `price\` (супербыстро, с кэшем).
2. **Только если подходящего нет** — быстрый интернет (FAPI).
3. Пока идёт работа — маленькое окно **% из 100**.

Интернет часто даёт чужие кроссы. Главный источник — ваши прайсы.

## 1. Пишите сканируемый код в названии в Excel

Когда приходуете товар, добавляйте код (тот, что будет в поле «Имя») в текст:

```
Шаровая опора GOLF WXQP /361337
```

или в номенклатуре `//OE361337//`. После F8 эта строка будет с меткой **[ВАШ ПРАЙС]**.

## 2. Первый F8 после смены прайсов чуть дольше

Строится кэш `logs\excel_index_cache.pkl`. Следующие нажатия F8 по Excel — почти мгновенные.

## 3. Если в списке нет нужного — ручной ввод

Внизу окна: Наименование → Модель → Бренд → «Использовать ручной ввод».

## 4. NTIN точнее с API-токеном

https://nationalcatalog.kz → Ключи API → в `config.ini`:

```ini
[ntin]
api_token = ВАШ_ТОКЕН
```

## 5. Искать также по колонке «Номер»

```ini
[excel]
excel_search_article_columns = true
```
