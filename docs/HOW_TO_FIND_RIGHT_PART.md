# Как повысить шанс найти НУЖНУЮ запчасть

Интернет (FAPI) часто находит «чужие» кроссы. Для вашего склада главный
источник — файлы в папке `price\`.

## 1. Пишите сканируемый код в названии в Excel (самое важное)

Когда приходуете товар, добавляйте код (тот, что будет в поле «Имя») в текст названия:

```
Шаровая опора GOLF WXQP /361337
```

После F8 эта строка будет сверху списка с меткой **[ВАШ ПРАЙС]**.

## 2. Выбирайте позиции с меткой [ВАШ ПРАЙС]

Не берите первые попавшиеся `[fapi]` — это чужой каталог кроссов.

## 3. Если в списке нет нужного — ручной ввод

Внизу окна: Наименование → Модель → Бренд → «Использовать ручной ввод».

## 4. NTIN точнее с API-токеном

Зарегистрируйтесь на https://nationalcatalog.kz → Ключи API → в `config.ini`:

```ini
[ntin]
api_token = ВАШ_ТОКЕН
```

Поиск NTIN идёт по короткому запросу: `Название Модель Бренд`.

## 5. Опционально: искать и по колонке «Номер»

Если код всё же лежит в «Номер»/«Каталожный №»:

```ini
[excel]
excel_search_article_columns = true
```
