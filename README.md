# דובאי טיקטס 🕌 | אתר אטרקציות לדובאי

אתר תדמית ומכירות לאטרקציות וכרטיסים בדובאי, בהשראת אתרים מובילים בתחום.
האתר בנוי בעברית (RTL), עיצוב מודרני ונקי, מותאם לנייד ולאייפון, וכולל
**באנר וואטסאפ צף** שמעביר מבקרים לקבוצת הוואטסאפ שלך.

## ✨ מה יש באתר

- עמוד נחיתה מלא עם תמונות איכותיות של דובאי
- קטגוריות אטרקציות, אטרקציות מובילות וכרטיסים משולבים (קומבו)
- חבילות נופש (בסיס / זוגית / אקסטרים)
- קטע המלצות מטיילים + דירוג כוכבים
- שאלות נפוצות (אקורדיון)
- **באנר וואטסאפ דביק תחתון + כפתור צ'אט צף** — מותאם לאייפון (safe-area)
- כל כפתור "לפרטים" פותח שיחת וואטסאפ עם הודעה מוכנה מראש

## 🛠️ התקנה והרצה

```bash
npm install      # התקנת תלויות
npm run dev      # הרצה מקומית (http://localhost:5173)
npm run build    # בניית גרסה לפרודקשן (תיקיית dist)
npm run preview  # תצוגה מקדימה של גרסת הפרודקשן
```

## ✏️ עריכת התוכן (בלי ידע בתכנות)

| מה לערוך | איפה |
| --- | --- |
| מספר וואטסאפ, קישור לקבוצה, אימייל, שם המותג | `src/data/site.ts` |
| אטרקציות, חבילות, מחירים, תמונות, המלצות, שאלות נפוצות | `src/data/content.ts` |

**חשוב מאוד לפני העלייה לאוויר:** בקובץ `src/data/site.ts` עדכן/י:
- `whatsappNumber` — מספר הוואטסאפ שלך בפורמט בינלאומי (לדוגמה `972501234567`).
- `whatsappGroupLink` — קישור ההזמנה לקבוצת הוואטסאפ שלך
  (וואטסאפ → פרטי קבוצה → הזמנה באמצעות קישור).

## 🚀 העלאה לאוויר (חינם)

לאחר `npm run build` נוצרת תיקיית `dist`. אפשר להעלות אותה לכל שירות אחסון סטטי:

- **Netlify / Vercel** — חברו את הריפו, הם יזהו את Vite אוטומטית.
- **GitHub Pages / Cloudflare Pages** — העלו את תוכן תיקיית `dist`.

React + TypeScript + Vite + Tailwind CSS.
