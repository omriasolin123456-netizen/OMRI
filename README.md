# Microinvest Склад Pro — помощник карточек автозапчастей

Автоматизация для **Microinvest Склад Pro 3.07.075** (Windows 11 x64): после сканирования кода в поле «Имя» помощник ищет запчасть, уточняет название по локальным прайсам и заполняет карточку.

## Рабочий сценарий

1. Откройте карточку нового товара в Microinvest.
2. Отсканируйте / введите код в поле **Имя** (например `361337`).
3. Горячие клавиши:
   - **F8** — полный цикл (Excel → интернет → имя / штрихкод / каталог=штрихкод / каталожный № / NTIN);
   - **F7** — только NTIN по текущему полю «Имя»;
   - **F4** — скопировать текст из «Штрих-код» в графу «Каталог» (`…_ad14`).
4. Помощник:
   - читает значение из поля «Имя» (это будущий **Штрихкод**);
   - **сначала** ищет в ваших Excel (`price\`);
   - **если в Excel пусто** — интернет (FAPI + фирмы/ключевые слова из `config.ini`);
   - показывает окно выбора (**Enter** подтверждает синюю/первую строку);
   - ищет **NTIN**;
   - заполняет поля Microinvest (штрихкод дублируется в «Каталог» `ad14`).

### Пример

| Поле | До | После |
|------|----|-------|
| Имя | `361337` | `Шарнир независимой подвески / поворотного рычага Toyota Camry WXQP` |
| Штрихкод | *(пусто)* | `361337` |
| Каталог (`ad14`) | *(пусто)* | `361337` (то же, что штрихкод) |
| NTIN | *(пусто)* | код из НКТ или пусто |

Формат имени из Excel (обязательный порядок):

**Наименование товара + Модель автомобиля + Бренд**

## Установка (Windows)

1. Установите [Python 3.10+](https://www.python.org/downloads/) (отметьте *Add to PATH*).
2. Установите [AutoHotkey 1.1 **Unicode**](https://www.autohotkey.com/) (`AutoHotkeyU64.exe`, не ANSI).
3. Скопируйте папку проекта на ПК.
4. Запустите `install.bat`.
5. Положите свои прайс-листы `.xlsx` в папку `price\`.
6. Запустите `run.bat` или `MicroinvestAssistant.ahk`.

### Если «Python не вернул результат» / код выхода 1
1. Запустите `install.bat` ещё раз.
2. ПКМ по иконке в трее → **Проверить Python**.
3. Смотрите файлы в `logs\`:
   - `python_stderr.log` — ошибка Python
   - `python_run.log` — какая команда запускалась
   - `python_crash.log` — падение до записи результата
4. В `config.ini` можно указать полный путь:
   ```
   [python]
   executable = C:\Users\...\AppData\Local\Programs\Python\Python312\python.exe
   ```

### NTIN (Национальный каталог товаров)

Публичный API сайта (без токена):

`POST https://nationalcatalog.kz/gw/search/api/v1/search`

Запрос: `Название Модель Бренд`. Если NTIN несколько — окно выбора.

```ini
[ntin]
gw_search = https://nationalcatalog.kz/gw/search/api/v1/search
; api_token = …   # опционально, официальный API v3
```

### Интернет-поиск фирм и слов

В `config.ini` → `[search]`:

- `preferred_brands` — WXQP, ESEE, OSSCA, CNAB, LEON, LADA, Superzing, Bear, BOSCH, CHECKSTAR
- `web_keywords` — автозапчасть, запчасть, авто (добавляются к запросу без фирмы)

## Excel-прайсы (`price\`)

Поддерживаются форматы, в т.ч. по вашим скриншотам:

1. Производитель | Товар
2. Наименование | Мадель/Модель | Бренд
3. Номенклатура `//OE…//`
4. **Артикул | Наименование | Модель | Торговая марка | Оригинальный номер**
5. **Код производителя | Номер OE | Наименование | Марка**

Код из «Имя» ищется по всей строке (Артикул, OE, Код производителя и т.д.).
**Каталожный номер** берётся из колонок `Оригинальный номер` / `Номер OE` / `Каталожный №` / `Номер`
или из фрагмента `//OE4A9513031B//` в номенклатуре → в поле Microinvest «Каталожный номер».
Итоговое имя: **Наименование + Модель + Бренд**.

Примеры в `price\`: `format4_supplier_artikul.xlsx`, `format5_kod_proizvoditelya.xlsx` и др.

## Настройки (`config.ini`)

| Секция | Параметр | Описание |
|--------|----------|----------|
| `[hotkey]` | `key` / `ntin_key` / `copy_catalog_key` | F8 / F7 / F4 |
| `[microinvest]` | `field_*` | ClassNN полей WinForms |
| `[paths]` | `price_dir` | Папка с `.xlsx` |
| `[search]` | `fapi_key`, `preferred_brands`, `web_keywords` | Интернет-поиск |
| `[ntin]` | `gw_search` | Публичный поиск NTIN (без токена) |

ClassNN по умолчанию (ваша сборка 3.07.075):

- Имя: `WindowsForms10.EDIT.app.0.19bf6b8_r8_ad110`
- Штрихкод: `WindowsForms10.EDIT.app.0.19bf6b8_r8_ad19`
- NTIN: `WindowsForms10.EDIT.app.0.19bf6b8_r8_ad11`
- Каталог (копия штрихкода): `WindowsForms10.EDIT.app.0.19bf6b8_r8_ad14`
- Каталожный номер (OE из Excel): `WindowsForms10.EDIT.app.0.34f5582_r8_ad18`

Если после перезапуска Windows суффикс `_r8_` изменился, AHK попытается найти поле по окончанию `_adNNN`. При сбое поправьте ClassNN в `config.ini` (через Window Spy AutoHotkey).

## Поведение при ошибках

- Товар не найден → поля **не меняются**, сообщение: `Товар по запросу … не найден.`
- Название найдено, NTIN нет → имя и штрихкод заполняются, сообщение: `Название найдено, NTIN отсутствует.`
- Несколько вариантов → окно выбора, без автовыбора «наугад».
- Кэш товаров **не используется** — каждый запуск делает новый поиск.
- Логи: `logs\assistant.log`, `logs\errors.log`.

## Ручной тест Python (без Microinvest)

```bat
python python\main.py --query 361337 --config config.ini
```

Если найдено несколько вариантов, откроется окно выбора.
