# Прайс-листы (.xlsx)

После F8 код из поля «Имя» ищется по ВСЕЙ строке Excel.

## Поддерживаемые форматы

1. **Производитель | Товар**
2. **Наименование | Мадель | Бренд**
3. **Номенклатура** `Название //OE…// БРЕНД [код]`
4. **Поставщик (скрин):** Артикул | Наименование | Модель | Торговая марка | Оригинальный номер
   → имя = `Наименование Модель Торговая марка`
   → поиск по Артикул / Оригинальный номер
5. **Код производителя | Номер OE | Наименование | Марка**
   → имя из Наименования (+ Марка авто), бренд из хвоста названия
   → поиск по Код производителя / Номер OE

## NTIN

Поиск через `https://nationalcatalog.kz/gw/search/api/v1/search` (без токена).
