# Прайс-листы (.xlsx)

Положите сюда свои Excel-файлы. Поддерживаются 3 формата:

## Формат 1 — Производитель + Товар
Колонки: Производитель | Товар | Каталожный № | ...
Имя в Microinvest: «Товар Производитель»
(модель уже внутри колонки Товар)

## Формат 2 — Наименование + Мадель + Бренд
Колонки: Номер | Наименование товара | Мадель | Бренд | ...
(опечатка «Мадель» поддерживается)
Имя в Microinvest: «Наименование товара Мадель Бренд»

## Формат 3 — Номенклатура со слэшами
Колонка: «Ценовая группа/ Номенклатура/ Характеристика номенклатуры»
Вид строки: Название Модель //OEНомер// БРЕНД
Имя в Microinvest: «Название Модель БРЕНД»

Каталожный № / Номер / OE НЕ используются для связи с полем «Имя».
