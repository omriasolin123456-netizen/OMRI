# Прайс-листы (.xlsx)

Чтобы помощник ЧАЩЕ находил НУЖНУЮ запчасть:

1) Кладите актуальные .xlsx в эту папку.
2) В названии товара указывайте код, который сканируете в Microinvest.
   Пример:  Шаровая опора GOLF WXQP /361337
   Тогда по коду 361337 позиция из прайса будет ПЕРВОЙ в списке [ВАШ ПРАЙС].
3) Формат итогового имени: Наименование  Модель  Бренд
4) Колонки «Каталожный №» / «Номер» для связи с полем «Имя» не используются
   (можно включить в config.ini: excel_search_article_columns = true).

Поддерживаемые форматы:
1. Производитель | Товар
2. Наименование товара | Мадель | Бренд
3. Номенклатура: Название //OE...// БРЕНД
