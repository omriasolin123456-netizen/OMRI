# Прайс-листы (.xlsx)

После F8 код из поля «Имя» (штрихкод) ищется по ВСЕЙ строке Excel:
номенклатура, Штрихкод, Номер, Артикул, Каталожный № — любая колонка.

Примеры строк, которые находятся по коду 320029:

1) Код в хвосте номенклатуры:
   Радиатор VW GOLF2 1.6 с отводом //OE191121253К// WXQP 320029

2) Код в отдельной колонке «Штрихкод» / «Номер» / «Артикул»

3) Код внутри названия:
   Шаровая опора GOLF WXQP /361337

Итоговое имя: Наименование  Модель  Бренд
(штрихкод уходит в поле «Штрихкод» Microinvest, не в имя)

Поддерживаемые форматы:
1. Производитель | Товар
2. Наименование товара | Мадель | Бренд
3. Номенклатура: Название //OE...// БРЕНД [штрихкод]
